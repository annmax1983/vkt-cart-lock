## 为什么选择 VKT Cart Lock？

大多数"防冲动消费"工具都留了后门：小睡、跳过、提前解锁。VKT Cart Lock 没有。它的意义在于保护你已经做好的决定，不让半夜盯着结账按钮的那个你毁掉它。

- **不能跳过、不能小睡、不能提前解锁。** 卸载插件是唯一的绕过方式。
- **计时器离开页面也继续走。** 关掉标签页、重启浏览器、明天再回来：锁还在。
- **到期默认静默。** 结账只是重新可用。Premium 可以加一次最终确认。
- **完成购买会开启新的锁。** 买完不等于习惯改变。
- **本地优先。** 计时器、设置、文案和统计都留在你的浏览器里。没有分析、没有广告，浏览历史不出设备。

## 工作原理

1. **第一次点击结账。** 拦截点击，启动计时器并显示锁屏。订单不会被提交。
2. **之后的每次尝试。** 结账保持锁定，遮罩倒计时显示剩余时间。
3. **计时器说了算。** 它存在插件存储里，不在标签页里。关闭页面、重新打开商店或重启浏览器都不会缩短它。
4. **时间到了。** 锁静默释放，结账恢复可用。Premium 用户可要求先点一次确认。
5. **购买之后。** 完成的订单开启新一轮冷却，下一次购买同样要经过这次停顿。

拦截只发生在页面内。它从不挂钩网络请求，也从不触碰支付 iframe 或支付服务商页面（Stripe、PayPal、Adyen、checkout.com、Braintree 及类似域名均被排除）。

## 使用方法

- **设置冷却时长。** 打开插件选项，选择一个预设；Premium 可自定义时长。
- **写你自己的话。** 锁屏可以显示你的文字而不是内置语录。轮换模式让它不会变成壁纸。
- **添加规则。** 把买菜网站加进允许列表，给小店强制上锁，或豁免低于设定金额的订单。
- **看徽章。** 工具栏倒计时是锁仍在生效的安静提醒。
- **看账本。** 仪表盘显示拦下了什么、原本要花多少钱、哪些站点和情绪触发最多结账，以及 12 个月趋势。
- **备份（Premium）。** 换电脑前用 JSON 导出。同步会恢复设置和计时器，但本地统计不会跟着走。

卸载插件会清除本地数据。如果启用了 Premium 同步，重装后文案和设置会回来；统计和本地历史不会。

## 数据与隐私

- **本地存储：** 设置、计时器、统计、自检记录、可选的设置 PIN（仅加盐 SHA-256 哈希）和 Premium 许可证记录。
- **同步（Premium，可选开启）：** 设置、自定义文案和精简计时器记录，通过 `chrome.storage.sync`。设置 PIN 绝不参与同步。
- **发送到许可证服务器：** 仅在激活、校验或停用 Premium 时——许可证密钥、随机安装 ID、插件 ID 和基础浏览器信息（浏览器版本、语言、时区、User-Agent）。
- **绝不收集：** 页面内容、浏览历史、购物车内容、支付信息、按键记录或分析数据。

没有账号、没有广告、不出售数据。卸载插件会移除本地数据；服务器端的许可证记录可通过先停用许可证来移除。

完整政策见 [privacy-policy.html](../privacy-policy.html)。

## 权限说明

| 权限 | 为什么需要 |
|------------|------------------|
| `storage` | 本地保存设置、计时器和统计；Premium 同步 |
| `alarms` | 保持倒计时准确并按时释放锁 |
| `notifications` | 新锁启动时显示本地桌面通知 |
| `host_permissions: <all_urls>` | 商店使用任意域名，需在任何站点检测结账按钮 |
| `host_permissions: api.annmax1983.com` | 激活与校验可选的 Premium 许可证 |

内容脚本在所有框架中运行，以便捕获店铺组件里的结账按钮，但支付服务商域名被明确排除。
