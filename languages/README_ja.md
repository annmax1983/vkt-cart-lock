# VKT Cart Lock

[English](../README.md) | [中文](README_zh.md) | [Deutsch](README_de.md) | [Español](README_es.md) | 日本語 | [Français](README_fr.md)

**カートに厳格なクーリングオフを。** チェックアウトをクリックするとタイマーが始まります。タイマーが終わるまでチェックアウトはロックされ、終了後に自動で解除されます。

中国語名は **冷静锁**（れいせいさ）です。

> Chromium · Manifest V3 · 6 言語 · トラッキングなし · ローカル優先

---

## VKT Cart Lock を選ぶ理由

多くの「衝動買い防止」ツールは抜け道を残しています：スヌーズ、スキップ、早期解除。VKT Cart Lock は違います。目的は、真夜中にチェックアウトボタンを睨んでいる自分から、あなたがすでに下した決断を守ることです。

- **スキップもスヌーズも早期解除もなし。** 拡張機能のアンインストールだけが唯一の回避策です。
- **タイマーはページの外でも進み続けます。** タブを閉じても、ブラウザを再起動しても、明日戻ってきても：ロックはそこにあります。
- **期限切れはデフォルトで静かです。** チェックアウトが再び使えるようになるだけ。Premium なら最後の確認を1回追加できます。
- **購入完了で新しいロックが始まります。** 買ったからといって習慣が変わるわけではありません。
- **ローカル優先。** タイマー、設定、メッセージ、統計はブラウザ内に残ります。分析も広告もなく、閲覧履歴が端末の外に出ることもありません。

## 仕組み

1. **最初のチェックアウトクリック。** ガードがクリックを遮断し、タイマーを開始してロック画面を表示します。注文は送信されません。
2. **その後のすべての試行。** チェックアウトはロックされたまま、オーバーレイが残り時間をカウントダウンします。
3. **タイマーが唯一の真実です。** タブではなく拡張機能のストレージに存在します。ページを閉じても、ショップを開き直しても、ブラウザを再起動しても短くなりません。
4. **時間になったら。** ロックは静かに解除され、チェックアウトが再び許可されます。Premium ユーザーは事前に1回の確認クリックを必須にできます。
5. **購入後。** 完了した注文は新しいクールダウンを開始し、次の購入も同じ一時停止を経ます。

ガードはページ内でのみ機能します。ネットワークリクエストにフックすることはなく、決済 iframe や決済プロバイダーのページ（Stripe、PayPal、Adyen、checkout.com、Braintree および類似ホストは対象外）には一切触れません。

## インストール

1. Chrome では `chrome://extensions/`、Edge では `edge://extensions/` を開きます。
2. **デベロッパーモード**をオンにします。
3. **パッケージ化されていない拡張機能を読み込む**をクリックし、このフォルダを選択します。
4. 拡張機能をツールバーにピン留めします。

パッケージ済みビルドには `publish/` の zip を使うか、開発中はフォルダを直接読み込んでください。

## 使い方

- **クールダウンを設定する。** 拡張機能のオプションでプリセットを選ぶか、Premium でカスタム時間を設定します。
- **自分の言葉を書く。** ロック画面に内蔵の名言ではなくあなたの言葉を表示できます。ローテーションモードなら壁紙化を防げます。
- **ルールを追加する。** 食料品サイトを許可リストに、小規模ショップにロックを強制、設定金額未満の注文を免除。
- **バッジを見る。** ツールバーのカウントダウンは、ロックがまだ有効であることを静かに教えてくれます。
- **台帳を確認する。** ダッシュボードには、何をブロックしたか、いくら使わずに済んだか、どのサイトと気分が最もチェックアウトを誘発するか、12 か月のトレンドが表示されます。
- **バックアップ（Premium）。** マシンを替える前に JSON エクスポートを。同期は設定とタイマーを復元しますが、ローカル統計は移動しません。

拡張機能をアンインストールするとローカルデータは消去されます。Premium 同期が有効なら、再インストール後にメッセージと設定が戻ります。統計とローカル履歴は戻りません。

## データとプライバシー

- **ローカル保存：** 設定、タイマー、統計、セルフチェックメモ、任意の設定 PIN（ソルト付き SHA-256 ハッシュのみ）、Premium ライセンス記録。
- **同期（Premium、オプトイン）：** 設定、カスタムメッセージ、スリムなタイマー記録を `chrome.storage.sync` 経由で。設定 PIN が同期されることはありません。
- **ライセンスサーバーへ送信：** Premium の有効化・検証・停止のときのみ——ライセンスキー、ランダムなインストール ID、プラグイン ID、基本的なブラウザメタデータ（ブラウザバージョン、言語、タイムゾーン、ユーザーエージェント）。
- **収集しないもの：** ページコンテンツ、閲覧履歴、カートの内容、決済情報、キー入力、分析データ。

アカウントも広告もデータ販売もありません。拡張機能をアンインストールするとローカルデータが削除されます。サーバー側のライセンス記録は、先にライセンスを停止することで削除できます。

完全なポリシーは [privacy-policy.html](../privacy-policy.html) をご覧ください。

## 権限

| 権限 | 必要な理由 |
|------------|------------------|
| `storage` | 設定・タイマー・統計のローカル保存と Premium 同期 |
| `alarms` | カウントダウンの精度維持と、時間どおりのロック解除 |
| `notifications` | 新しいロックの開始時にローカル通知を表示 |
| `host_permissions: <all_urls>` | ストアは任意のドメインを使うため、どのサイトでもチェックアウトボタンを検出 |
| `host_permissions: api.annmax1983.com` | 任意の Premium ライセンスの有効化と検証 |

コンテンツスクリプトはすべてのフレームで実行され、ストアフロントウィジェット内のチェックアウトボタンを捕捉しますが、決済プロバイダーのホストは明示的に除外されます。
